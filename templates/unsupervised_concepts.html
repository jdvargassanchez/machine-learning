What is Unsupervised Learning?

Unsupervised Learning is a type of machine learning where the model is trained on unlabeled data. Unlike supervised learning, there are no correct answers or target variables. The algorithm must discover patterns, structures, or relationships within the data on its own.

Common applications include:

  • Customer segmentation
  • Anomaly detection
  • Data compression
  • Pattern recognition

What is Clustering?

Clustering is a type of unsupervised learning that involves grouping similar data points together. The goal is to partition a dataset into clusters where:

  • Points within the same cluster are similar to each other
  • Points in different clusters are different from each other

It is widely used for exploratory data analysis and finding natural groupings in data.

What is K-Means?

K-Means is one of the most popular and straightforward clustering algorithms. It partitions data into K distinct, non-overlapping clusters (groups). The algorithm works iteratively to assign each data point to one of K clusters based on the distance to the cluster centers (centroids).

The name "K-Means" comes from the fact that each cluster is represented by the mean (average) of all points in that cluster.

Centroids

A centroid is the center of a cluster. In K-Means, each cluster has a centroid, which is calculated as the mean (average) position of all points in that cluster.

Initially, centroids are chosen randomly. Then, the algorithm repeatedly recalculates them as points are reassigned to clusters. The final centroids represent the "heart" of each cluster.

Centroid = (x₁, x₂, ..., xₙ)

Where x is the average of each feature within the cluster.

Distance Metrics: Euclidean Distance

In K-Means, the Euclidean distance is the most common metric used to measure how far a data point is from a centroid. It represents the straight-line distance between two points in multi-dimensional space.

d(p, q) = √[(p₁ - q₁)² + (p₂ - q₂)² + ... + (pₙ - qₙ)²]

For two features (2D space), the formula simplifies to:

d = √[(x₁ - x₂)² + (y₁ - y₂)²]

The point is assigned to the cluster whose centroid has the smallest Euclidean distance.

Iterative Process of K-Means

The K-Means algorithm follows a simple 4-step iterative process:

  1. Initialize: Choose K random centroids.
  2. Assign: Assign each data point to the nearest centroid (using Euclidean distance).
  3. Update: Recalculate centroids as the mean of all points in each cluster.
  4. Repeat: Repeat steps 2-3 until convergence (no changes in cluster assignments).

This process typically runs for a fixed number of iterations or until the centroids stop moving significantly.

Variance and Convergence

Within-Cluster Variance measures how spread out the points are within a cluster. The goal of K-Means is to minimize this variance (make clusters as tight as possible).

Convergence happens when the centroids no longer change significantly between iterations, or when cluster assignments become stable. The algorithm stops at this point.

As iterations progress, the total variance decreases - which is why we can visualize it with a decreasing line graph.

Real-World Applications of K-Means

K-Means clustering is used across many industries:

  • Customer Segmentation: Grouping customers by purchasing behavior for targeted marketing.
  • Image Compression: Reducing the number of colors in an image by grouping similar colors.
  • Anomaly Detection: Identifying unusual patterns in network traffic or transactions.
  • Document Clustering: Organizing news articles or research papers by topic.
  • Geolocation Analysis: Identifying crime hotspots or optimal store locations.
  • Genetics: Grouping genes with similar expression patterns.
