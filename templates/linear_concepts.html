Linear Regression — Basic Concepts

Supervised Learning · Regression

What is Linear Regression?

Linear Regression is one of the most fundamental algorithms in supervised machine learning. It models the relationship between a dependent variable (target) and one or more independent variables (features). The main objective is to find a mathematical relationship that can be used to predict future values.

This model assumes a linear relationship between variables: when the input variable changes, the output changes proportionally. It is widely used for predicting prices, sales, and trends.

Independent and Dependent Variables

In linear regression, variables are divided into two main types:

Independent Variable (X): The input or predictor variable — the data used to make predictions.

Dependent Variable (Y): The output or target variable — the result we want to predict.

For example, predicting a student's grade based on study hours:

  • X = Study Hours
  • Y = Final Grade

Training Data

Training data is a dataset that contains both input variables and their corresponding output values. This data is used to train the model so that it can learn the relationship between variables.

The quality and size of the training data directly affect model accuracy. A good dataset should be representative, clean, and relevant to the problem.

Regression Line

The regression line is the line that best fits the data points in a graph. It represents the predicted relationship between X and Y. The goal is to find the line that minimizes the difference between predicted and actual values — known as the error.

Slope and Intercept

The equation of a simple linear regression model is:

Y = m·X + b

Slope (m): How much Y changes for each unit increase in X.

Intercept (b): The value of Y when X equals zero.

These parameters define the position and direction of the regression line.

Example of Application

A common real-world example is predicting house prices. The house size (square meters) serves as the independent variable (X), and the price is the dependent variable (Y).

By training the model with historical data, it becomes possible to estimate the price of new houses based on their size — helping real estate companies, buyers, and investors make better decisions.
