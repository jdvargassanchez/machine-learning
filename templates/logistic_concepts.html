Logistic Regression — Basic Concepts

Supervised Learning · Classification

What is Logistic Regression?

Logistic Regression is a supervised machine learning algorithm used for classification problems. Instead of predicting continuous values, it predicts probabilities that map to discrete classes.

It is commonly used for binary classification tasks such as spam detection, disease prediction, or determining whether a transaction is fraudulent or not.

Independent and Dependent Variables

In logistic regression, variables are defined as:

Independent Variable (X): Input features used to make predictions.

Dependent Variable (Y): Output variable, usually categorical (e.g., 0 or 1).

Example:

  • X = Study Hours
  • Y = Pass (1) or Fail (0)

Sigmoid Function

Logistic regression uses the sigmoid (logistic) function to transform predictions into probabilities between 0 and 1.

P(Y=1) = 1 / (1 + e^(-z))

This function produces an S-shaped curve, making it ideal for classification tasks.

Decision Boundary

The decision boundary is the threshold used to classify data into categories. Typically, if the predicted probability is greater than 0.5, the output is classified as 1; otherwise, it is classified as 0.

Training Data

Training data consists of labeled examples used to teach the model how to classify inputs correctly. The model learns by adjusting its parameters to minimize classification error.

Cost Function

Logistic regression uses a cost function called Log Loss (or cross-entropy loss), which measures how well the predicted probabilities match the actual labels.

Example of Application

A bank uses logistic regression to decide whether to approve a loan. It analyzes variables such as income, credit history, and debt, and calculates the probability that the customer will default. If the probability exceeds a certain threshold, the loan is rejected; if it is low, it is approved.
