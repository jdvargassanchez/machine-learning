How QDA Works

Quadratic Discriminant Analysis (QDA) is a classification algorithm that models each class using a Gaussian distribution. Unlike linear models, QDA allows each class to have its own covariance matrix, producing curved decision boundaries.

  • Compute mean (μ) for each class
  • Compute covariance matrix (Σ)
  • Evaluate discriminant function
δₖ(x) = -½ ln|Σₖ| - ½ (x - μₖ)ᵀ Σₖ⁻¹ (x - μₖ)

Dataset Explanation

The dataset contains two clearly separated groups:

  • Class A 🔵: Points concentrated in the lower-left region
  • Class B 🔴: Points concentrated in the upper-right region

QDA learns the distribution of each group and decides which class a new point belongs to based on probability.
