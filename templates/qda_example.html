Quadratic Discriminant Analysis (QDA)

A probabilistic classification model with quadratic decision boundaries

🧠 How does it work?

For each class, QDA calculates:

  • The mean vector (μ)
  • The covariance matrix (Σ)
  • The prior probability (π)

Then, for a new data point x, it evaluates a discriminant function for each class and assigns the point to the class with the highest score.

Discriminant Function:

δₖ(x) = -½ ln|Σₖ| - ½ (x - μₖ)ᵀ Σₖ⁻¹ (x - μₖ) + ln πₖ

📊 Dataset Description

In this example, we use a simple 2D dataset with two classes:

  • Class A (blue): Points clustered around lower values
  • Class B (red): Points clustered around higher values

The goal is to classify a new point based on its position relative to these distributions.
