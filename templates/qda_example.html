Quadratic Discriminant Analysis

Supervised Learning · Classification

How it works:

  • Compute the mean vector (μ) for each class
  • Compute the covariance matrix (Σ)
  • Evaluate the discriminant function
δₖ(x) = -½ ln|Σₖ| - ½ (x - μₖ)ᵀ Σₖ⁻¹ (x - μₖ)

Dataset Description

This example uses a simple 2D dataset with two classes:
